# SingIt Privacy Policy

The privacy policy is the web page [`website/privacy/index.html`](../website/privacy/index.html), published at
https://singitai.app/privacy/. That page is the only source: edit it there, and keep it in step with the code it
describes (what each store collects and keeps, the providers a request goes to).

Data requests and deletion: https://singitai.app/data-deletion/. Contact: contact@singitai.app.
