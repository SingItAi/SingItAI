## Verification and limitations

Dependency-free structural tests cover OpenAPI version, reference resolution, operation IDs, security, source route membership, redirects, headers, metadata, sitemap, internal links and restricted public content. No package installation is required. Redocly is not installed locally; its network installation is skipped. The website suite and generated model-page check are run before handoff.

This is documentation and static hosting configuration, not new Solana payment functionality. No Solana-specific limit is asserted. Existing production configuration was not inspected, no deployment was performed, and no new live endpoint behavior is claimed. The app, models and request formats are sourced above; there are no unsourced numerical or behavioral claims.

Final local results: both new test files pass, and `node scripts/generate-model-pages.mjs --check` reports 215 pages with zero differing files. `node --test website/tests/*.test.mjs` passes 22 test files and fails four existing build-output tests (`404`, `pricing`, `seo-files`, `seo-landing-pages`), each because the build subprocess returns empty captured stdout instead of its output path. All four failures reproduce using an unchanged HEAD archive in `/tmp`; direct `node website/build.mjs /tmp/singit-api-reference-build` succeeds. The local runtime is Node 24.22.1; CI targets Node 22. The unrelated build tests were left unchanged.
