Call it with x402

curl -i https://ask.singitai.app/v1/chat/completions \
  -H 'Content-Type: application/json' \
  -d '{"model":"qwen3-next-80b-a3b-instruct","max_tokens":200,"messages":[{"role":"user","content":"Hello"}]}'

The unpaid POST returns HTTP 402 and a PAYMENT-REQUIRED header: base64 JSON, x402 v2. Sign one offer (upto first, then exact; Base then Solana) and retry the same request with the PAYMENT-SIGNATURE header. HTTP 200 returns choices[0].message.content and billing.totalAtomic.

FAQ

What is x402?

x402 is an HTTP payment protocol. An unpaid request returns HTTP 402 with a payment offer; sign one offer and retry the same request with proof of payment.

Do I need an account?

No account or API key is needed for these x402 calls.

Which network? Base?

Base or Solana, paid in USDC. This page focuses on Base.
