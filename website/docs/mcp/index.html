SingIt MCP

A remote Streamable HTTP server with JSON responses only. No local server installation is needed. Endpoint: https://app.singitai.app/mcp. Official MCP Registry name: app.singitai/singit. Server: singit, “SingIt x402”, version 0.1.3; protocol 2025-06-18.

Get a key

MCP key with spending limits: setup, refusal and revocation.

Open SingIt, then Settings → API keys. Free tools and tools/list work without a key. Export SINGIT_API_KEY in the environment that launches your client. Paid tools are paid per call within the key’s caps; get_limits shows what is spent and left today. See spending limits and developer setup.

Install

Claude Code

Verification: Command checked against Claude Code docs, 31 October 2026; not run here.

claude mcp add --transport http singit https://app.singitai.app/mcp --header 'Authorization: Bearer ${SINGIT_API_KEY}'

Verification: Documented client checks; not run here.

claude mcp list
claude mcp get singit
# In Claude Code: /mcp

For a shared project, use this .mcp.json entry. Claude Code requires type: http for a URL entry.

Verification: From the Claude Code docs, 31 October 2026 (it expands ${VAR} in headers); not run here.

{
  "mcpServers": {
    "singit": {
      "type": "http",
      "url": "https://app.singitai.app/mcp",
      "headers": {
        "Authorization": "Bearer ${SINGIT_API_KEY}"
      }
    }
  }
}

Verification: run against the live server on 31 October 2026, no key.

curl -sS https://app.singitai.app/mcp \
  -H 'Content-Type: application/json' \
  -H 'Accept: application/json, text/event-stream' \
  -d '{"jsonrpc":"2.0","id":2,"method":"tools/list"}'

Expected: initialize returns serverInfo.version 0.1.3; tools/list returns 16 tools. Both requests are free and need no key. A missing, empty or unexpanded-variable header behaves like no key. A wrong or revoked key gets HTTP 401 (verified 31 October 2026 with an invalid key).

Troubleshooting

SymptomCauseFix
HTTP 401Bad or revoked key.Create a valid key and replace the header.
Paid tool asks for a key after configurationThe header contains a literal ${env:...}, or the variable was not exported to the launching process.Export SINGIT_API_KEY in the client’s launch environment; check its interpolation syntax and restart.
Scope missingThe key lacks search for web_search/read_page, or tools for market data.Create a key with the needed scope; older keys may lack tools.
Daily or per-request limit reachedThe call exceeds the key’s caps.Inspect get_limits for remaining spend and caps. The wallet signs a key’s limits; adjust them through the app.
Solana account refused by a market toolMarket-data tools are Base-only for now.Use a Base account for these tools. web_search and read_page support Base or Solana.
SSE/stdio-only client cannot connectThe server uses Streamable HTTP with JSON responses only.Use a client with remote HTTP support.
Tool list empty or cached after a config changeClient configuration or discovery needs refreshing.Restart the client after editing; in Claude Code use /mcp to reconnect.
Claude Code reports a URL without a typeThe shared .mcp.json entry lacks type.Set "type": "http" in the singit entry.
