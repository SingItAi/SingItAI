How this list was checked

This is the keyless tools/list snapshot fetched 31 October 2026 and re-checked against the live server on 2 November 2026: the same 16 tools, descriptions, input schemas and annotations. The live server reports version 0.1.3; the repository declares 0.1.4 with the same tool set. The live response additionally has a top-level title per tool matching annotations.title.

Spending limits

The key's daily and per-request caps are enforced by SingIt's server for calls made with that key to SingIt's MCP and the same key's /v1 endpoint. They do not limit what an agent spends anywhere else. SingIt's contracts do not protect other people's agents' own wallets.

Paid calls are charged to the key's own limits in USDC. A refused call returns isError true and nothing is charged. Repeating a paid call charges again. Read-only tools can still cost money. get_limits shows what is spent and left today. See MCP key setup and agent spending limits.

Free lookups

get_price

Current price of a major cryptocurrency, gold or silver (Chainlink on Base), or an exchange rate between two currencies. Use for quick quotes of well-known assets; call list_price_symbols when unsure a symbol is covered. Free, no key needed.

get_price parameters
NameTypeRequired/optionalAllowed valuesDescription and bounds
kindstringrequiredcrypto, metal, fxWhat kind of price to look up.
symbolstringoptionalNoneTicker for crypto or metal, e.g. BTC, XAU.
basestringoptionalNoneBase currency for fx, e.g. USD.
quotestringoptionalNoneQuote currency for fx, e.g. EUR.

Key needed? No; scope: Free; none; network: No payment; readOnlyHint: true; idempotentHint: true.

list_price_symbols

Every crypto, metal and currency symbol get_price supports. Call it before get_price when unsure a symbol is covered. Free, no key needed.

Parameters: None

Key needed? No; scope: Free; none; network: No payment; readOnlyHint: true; idempotentHint: true.

list_models

The AI models (chat, images or audio) available through SingIt, with their prices. They are called through SingIt's OpenAI-compatible API at https://app.singitai.app/v1 (or https://ask.singitai.app over x402), not through these MCP tools. Free, no key needed.

Key needed? No; scope: Free; none; network: No payment; readOnlyHint: true; idempotentHint: true.

Your account, free and read-only, needs a key

get_balance

Your SingIt API balance: available and held USDC, auto top-up and pending top-ups. Use to check funds before paid calls. Free, but needs your API key.

Parameters: None

Key needed? Yes; free, read-only; scope: Account read; no paid-tool scope; network: Account data; readOnlyHint: true; idempotentHint: true.

get_limits

What your API key may still spend: its daily and per-request caps, spent and remaining today, scopes and expiry, plus your account's balance and, on Base, your allowance limiter (caps, left today, approved from your wallet, paused = emergency stop, expired). Read-only: it cannot change a limit. Use before a paid call to see whether it fits. Free, but needs your API key.

Parameters: None

Key needed? Yes; free, read-only; scope: Account read; no paid-tool scope; network: Account data; readOnlyHint: true; idempotentHint: true.

get_receipts

Your recent receipts, newest first: for each, its id, time, model, USDC charged, tokens and the upstream reference (kind charge, this key only), or the account's top-ups and refunds with their transaction and network. Read-only; page back with `before`. Free, but needs your API key.

get_receipts parameters
NameTypeRequired/optionalAllowed valuesDescription and bounds
limitintegeroptionalNoneHow many, newest first. Defaults to 10. minimum: 1; maximum: 50
kindstringoptionalcharge, topup, refundcharge (default): what this key spent; topup: money added to the account; refund.
beforeintegeroptionalNoneOnly entries older than this receipt id: pass the last id of the previous page. minimum: 1

Key needed? Yes; free, read-only; scope: Account read; no paid-tool scope; network: Account data; readOnlyHint: true; idempotentHint: true.

Web, paid per call, search scope, USDC on Base or Solana

web_search

Searches the web through Exa and returns titles, URLs and snippets of matching pages. Use for current or niche information, then read_page for a full page. Paid per call from your key's SingIt limits in USDC on Base or Solana; needs the key's "search" scope.

web_search parameters
NameTypeRequired/optionalAllowed valuesDescription and bounds
querystringrequiredNoneWhat to search the web for.
numResultsintegeroptionalNoneDefaults to a few. minimum: 1; maximum: 10
typestringoptionalauto, fast, neural, keyword

Key needed? Yes; paid; scope: search; network: USDC on Base or Solana; readOnlyHint: true; idempotentHint: false.

read_page

The readable text of one web page (up to 8000 characters), through Exa. Use after web_search, or when you already have a URL. Paid per call from your key's SingIt limits in USDC on Base or Solana; needs the key's "search" scope.

read_page parameters
NameTypeRequired/optionalAllowed valuesDescription and bounds
urlstringrequiredNoneThe http(s) page to read.

Key needed? Yes; paid; scope: search; network: USDC on Base or Solana; readOnlyHint: true; idempotentHint: false.
