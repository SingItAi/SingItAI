How this list was checked

This reference is generated from the repository's tool list (16 tools, including the free chat_free and the paid chat). The live server keeps listing 17 tools until sign402-web-api is restarted with this code; nothing here was checked against it again.

Spending limits

The key's daily and per-request caps are enforced by SingIt's server for calls made with that key to SingIt's MCP and the same key's /v1 endpoint. They do not limit what an agent spends anywhere else. SingIt's contracts do not protect other people's agents' own wallets.

Paid calls are charged to the key's own limits in USDC. A refused call returns isError true and nothing is charged. Repeating a paid call charges again. Read-only tools can still cost money. get_limits shows what is spent and left today. See MCP key setup and agent spending limits.

Current price of a major cryptocurrency, gold or silver (Chainlink on Base), or an exchange rate between two currencies. Use for quick quotes of well-known assets; call list_price_symbols when unsure a symbol is covered. Free, no key needed.

list_models

The AI models (chat, images or audio) available through SingIt, with their prices. Chat models can be called with chat or through SingIt's OpenAI-compatible API at https://app.singitai.app/v1. chat_free

Free model answers, no key needed. Answers are short (400 tokens), with a small daily allowance shared per network and a shared daily budget that can run out. To pay for a model answer with your key use chat with the same model without the free/ prefix.

Chat, paid per call, no extra scope, USDC on Base or Solana

chat

Paid per call from your key's SingIt balance and owner-set limits in USDC. The server enforces per-request and daily caps; a call over a cap is refused before anything is charged. Use list_models for model ids and prices, get_allowance (or get_limits) for what remains and which cap would refuse a call, and get_receipts for the charge. Pass max_tokens high enough for reasoning models: thinking uses the same budget.

chat parameters
NameTypeRequired/optionalAllowed valuesDescription and bounds
promptstringoptionalNoneThe question, as one user message. Send exactly one of prompt or messages.
messagesarrayoptionalNoneA whole conversation instead of prompt: text messages, oldest first.
modelstringoptionalNoneA SingIt model id from list_models, without a free/ prefix. Omit it for SingIt's default model.
max_tokensintegeroptionalNoneLongest answer, in tokens (1 to 8192, default 1024). Reasoning models think inside this budget, so leave room. minimum: 1; maximum: 8192
systemstringoptionalNoneAn optional system message; only together with prompt.

Key needed? Yes; paid; scope: No extra scope; network: USDC on Base or Solana; readOnlyHint: true; idempotentHint: false.

Your SingIt API balance: available and held USDC, auto top-up and pending top-ups. Use to check funds before paid calls. Free, but needs your API key.

get_limits

What your API key may still spend: its daily and per-request caps, spent and remaining today, scopes and expiry, plus your account's balance and your allowance limits on Base or Solana (caps, left today, approved from your wallet, paused = emergency stop, expired). Read-only: it cannot change a limit. Use before a paid call to see whether it fits. Free, but needs your API key.

Parameters: None

Key needed? Yes; free, read-only; scope: Account read; no paid-tool scope; network: Account data; readOnlyHint: true; idempotentHint: true.

get_allowance

How much you can still spend right now, before you pay: your API key's remaining today and per-request cap, and your wallet allowance's remaining today, per-purchase cap and approval on Base or Solana, each with spendableNowUsd and bindingLimit (the limit that would refuse a larger call). Owner can pause (Emergency stop) or Revoke the allowance: Base AgentAllowance is on-chain; Solana daily and per-purchase limits are server-checked. Read-only: it cannot change a limit. Free, but needs your API key.

Parameters: None

Key needed? Yes; free, read-only; scope: Account read; no paid-tool scope; network: Account data; readOnlyHint: true; idempotentHint: true.

get_receipts

Your recent receipts, newest first: for each, its id, time, model, USDC charged, tokens and the upstream reference (kind charge, this key only), or the account's top-ups and refunds with their transaction and network. Read-only; page back with `before`. Free, but needs your API key.
