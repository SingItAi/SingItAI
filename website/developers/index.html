Quickstart

Your first answer in one request.

For your own code or agent. To chat, open SingIt instead.

  1. Start freeModel free/deepseek-v4.1-flash answers with no wallet and no key: 20 answers a day.
  2. Get a keyIn the SingIt app, Settings → API keys. Your wallet signs the key's limits: a day, a request, how many days.
  3. Top upBuy a balance for your keys, $1 to $50 at a time, in USDC from your wallet. Each request costs what it used + 30%, with no fee per call.
  4. Use it anywhereThe OpenAI SDK, the Anthropic SDK or Claude Code, at app.singitai.app/v1, with any id from the model list. Agents with a wallet can skip the key and pay per answer over x402.

Python · key

from openai import OpenAI

# The official OpenAI SDK, pointed at SingIt, with a key from the SingIt app.
client = OpenAI(base_url="https://app.singitai.app/v1", api_key="sk_singit_...")
answer = client.chat.completions.create(
    model="claude-opus-5.5",
    messages=[{"role": "user", "content": "Hello!"}],
)
print(answer.choices[0].message.content)

Web search too: Exa's SDK with base_url="https://app.singitai.app/v1/exa" and the same key, paid per search from your wallet. Streaming, tools and images work as the model offers them. Each answer carries billing.chargedAtomic: what it took from your balance, in USDC micro-units. /v1/responses, /v1/balance and /v1/usage answer too.

x402 · no key

import { wrapFetchWithPayment, x402Client } from "@x402/fetch";
import { UptoEvmScheme } from "@x402/evm/upto/client";
import { createPublicClient, http } from "viem";
import { privateKeyToAccount } from "viem/accounts";
import { base } from "viem/chains";

// A wallet holding a little USDC on Base. No ETH: the facilitator pays the gas.
const account = privateKeyToAccount(process.env.AGENT_KEY);
const chain = createPublicClient({ chain: base, transport: http() });
const client = x402Client.fromConfig({ schemes: [{ network: "eip155:8453",
  client: new UptoEvmScheme({ address: account.address, signTypedData: account.signTypedData,
                              readContract: chain.readContract.bind(chain) }) }] });
const pay = wrapFetchWithPayment(fetch, client);

const res = await pay("https://ask.singitai.app/v1/chat/completions", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({ model: "claude-opus-5.5",
                         messages: [{ role: "user", content: "Hello!" }] }),
});
const answer = await res.json();
console.log(answer.choices[0].message.content, answer.billing.totalAtomic);

For agents with their own wallet: no account and no key, just a little USDC on Base. The payment is upto: you sign a ceiling, and Coinbase's facilitator settles only what the answer used (billing.totalAtomic, in USDC micro-units). A failed answer is never settled.

How payment works

Pays what it used. Stops at your limit.

The agent signs a ceiling and is charged the actual cost of the answer. Paying from a SingIt budget, it cannot go past the limits you set, and says why when it stops.

ask claude-opus-5.5 "Review this pull request"
← 402 Payment Required · ceiling 0.054 USDC
→ signed upto 0.054 USDC on Base
✓ 200 · answered · charged 0.0071 USDC, what it used
buy "Steam gift card, $25"
→ Bitrefill · Steam $25 · 25.13 USDC
✕ Over your $10 per-purchase limit. Nothing was paid.
One signature in your wallet raises it.

An example run. Ceilings and charges depend on the model and the answer.

Safety

A budget, not a hot wallet.

A key on disk

  • The agent's key holds the whole balance
  • A leaked key is lost money
  • Limits live in the agent's own software
  • Stopping it means moving the funds out

SingIt

  • USDC stays in your own wallet
  • Daily and per-purchase limits in a contract on Base
  • An API key spends only the balance you bought, within its own limits
  • One click revokes a key; one signature revokes the limits
